# 8D Issue Automation v2.4

8D PowerPoint를 읽어 Issue DB Excel과 주간회의 PPT를 업데이트하는 오프라인 규칙 기반 프로그램입니다.

## v2.4 변경점
- 주간회의 8D 상세 페이지의 2D~7D 내용을 한 셀에 합치지 않고 템플릿의 구역/라벨을 찾아 개별 입력
- 표(Table) 내부에 있는 `이슈명`, `과제명`, `담당자`, `발생 일자`, `Signal`도 인식해 업데이트
- 발생일자 `26.05.06` 형식을 2026년 / 05월로 Excel에 기록
- 결과 Excel/PPT가 열려 있어 저장이 막히면 시간표시 파일명으로 자동 저장
- 기존 상태 판정 및 기존 이슈 매칭 로직 유지

## 실행
1. 최초 1회 `setup.bat` 실행
2. 이후 `run.bat` 실행
3. `8D 내용 미리보기`로 추출 결과를 먼저 확인
4. 확인 후 `자동 업데이트 실행`

## 결과
원본 파일과 같은 폴더의 `자동화_결과`에 결과가 생성됩니다.
