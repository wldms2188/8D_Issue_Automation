# 8D Issue Automation

8D PowerPoint를 읽어 Issue DB Excel과 주간회의 PPT를 업데이트하는 오프라인 규칙 기반 프로그램입니다.

## 핵심 규칙
- 담당팀 / 담당자 / 폼팩터 / 제품 타입 / 발생 샘플 / 개발 단계: 프로그램에서 입력
- 발생처: 8D의 `발생 Site`에서 자동 추출
- 6D에 `검증 완료` 또는 단독 `완료`: `개선 완료`
- `완료 예정`, `완료 추정`, `진행중`, `검증중`, `예정`, `추정`: `개선 검증중`
- 4D와 5D가 모두 없고 6D 상태도 없으면: `원인/개선 미확인`
- 기존 이슈는 PMS/PLM 이슈번호를 최우선으로 Excel에서 검색
- 원본 Excel/PPT는 수정하지 않고 `자동화_결과`에 저장

## 실행
```bat
run.bat
```
또는
```bat
py app\main.py
```

## 배포용 EXE
```bat
build_exe.bat
```

## 실제 파일 테스트
실제 회사 파일은 GitHub에 올리지 말고 회사 PC에서 프로그램으로 선택하세요. 먼저 `8D 내용 미리보기`로 추출 결과를 확인한 후 자동 업데이트를 실행합니다.
